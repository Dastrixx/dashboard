# Расширение 1С «dashboard»

HTTP-сервис для дашборда по ТЗ «передача данных из 1С в дашборд аналитики продаж».
Конфигурация: 1С:Розница для Кыргызстана 2.3.5.35, платформа 8.3.24.

## Состав

- `CommonModule.bsl` — вся логика (общий модуль `дш_ДашбордСервер`, сервер + внешнее соединение).
- `Module.bsl` — модуль HTTP-сервиса `дш_Дашборд`, тонкая обёртка.
- `generate.py` — собирает XML-исходники расширения в `src/` (заимствованные объекты,
  роль `дш_ЧтениеДанныхДашборда` с правом «Чтение», общий модуль, HTTP-сервис).
- `CacheModule.bsl` — модуль `дш_ДашбордКэш` (повторное использование на время сеанса), кэш выборок для постраничной выдачи.
- `AdminModule.bsl` — модуль `дш_ДашбордАдминистрирование`: `УстановитьПользователяДашборда(Имя, Пароль)`
  создаёт пользователя через справочник «Пользователи» (только для администратора).
- `test-com.ps1` — проверка всех методов через COM, без веб-сервера.
- `com-bridge.ps1` — временный HTTP-мост на localhost:8099 к расширению через COM (для разработки дашборда).

Адреса: `/hs/dashboard/v1/{sales|returns|checks|stock|receipts|writeoffs|recounts|products|stores|sellers|suppliers|ping}`.
Параметры: `from`, `to` (ГГГГ-ММ-ДД; продажи/возвраты/чеки — до 31 дня, документы — до 366),
`date` (для stock), `limit` (до 5000), `offset`. Ответ: `{"data": [...], "total", "limit", "offset"}`,
ошибка: `{"error": "..."}` с кодом 400/404/500 (при 500 наружу уходит короткий текст,
подробности — в журнале регистрации, событие «Дашборд.Выгрузка»).

### Откуда берутся данные (отличия от ТЗ)

- `sales` (с версии 1.2.0) — из регистра «Продажи», как отчёты 1С и OData: `qty`, `sum`,
  `discount` (СтоимостьБезСкидок − Стоимость) и `cost` (ор_Себестоимость) за август 2026
  совпали с OData до копейки. Регистр уже за вычетом возвратов, строки бывают отрицательными;
  вычитать `returns` из `sales` не нужно. В 1.1.0 продажи брались из чеков и расходились
  с отчётами 1С: ручные правки отчётов о розничных продажах (−582 за август) и скидки
  по возвращённым товарам (+104 556 за август).
- `returns` — из строк пробитых и архивных чеков возврата (`Документ.ЧекККМ.Товары`):
  сколько вернули на кассе. Продавец — из строки чека, если пусто — из шапки. `cost` = 0.
- `checks` — без черновиков (не проведённых чеков с пустым статусом), поэтому за август
  на 3 чека продажи меньше, чем насчитывает основной дашборд по OData.
- Постраничная выдача: результат выборки кэшируется на время сеанса (модуль `дш_ДашбордКэш`,
  повторное использование «на время сеанса») в пределах 5-минутного интервала, поэтому страницы
  `offset` одной выгрузки не выполняют запрос заново. Сортировка — по всем полям группировки.

## Сборка и загрузка в базу

```powershell
python -I onec-extension\generate.py <папка DumpConfigToFiles основной конфигурации>
$exe = "C:\Program Files\1cv8\8.3.24.1819\bin\1cv8.exe"
$base = 'DESIGNER /F"<база>" /N"<админ>" /P"<пароль>" /DisableStartupDialogs'
& $exe ($base + ' /LoadConfigFromFiles "onec-extension\src" -Extension dashboard')
& $exe ($base + ' /UpdateDBCfg -Extension dashboard')
& $exe ($base + ' /CheckModules -Server -ExternalConnection -Extension dashboard')
```

Важно: 1cv8.exe запускать из PowerShell, не из Git Bash (он портит аргументы `/F`, `/N`).

## Пользователь для дашборда

Вызвать под администратором (COM или консоль кода):

```
дш_ДашбордАдминистрирование.УстановитьПользователяДашборда("dashboard_api", "<пароль>")
```

Функция создаёт элемент справочника «Пользователи» и пользователя ИБ, а также профиль
и группу доступа «Дашборд: чтение данных (HTTP-сервис)» с единственной ролью
`дш_ЧтениеДанныхДашборда` (в Рознице роли раздаются только через группы доступа БСП).
Внешнее соединение и интерактивный вход этому пользователю недоступны — только HTTP-сервис.

Если COM-вызов падает с «Предупреждение безопасности … Разрешить открывать?», это защита
от опасных действий: подтвердить её в COM-сеансе некому. Для локальной копии базы в
`C:\Program Files\1cv8\conf\conf.cfg` (файл в UTF-16) добавлена строка
`DisableUnsafeActionProtection=.*1c-base.*`. На рабочей базе так не делать — там
пользователя создаёт специалист 1С интерактивно.
